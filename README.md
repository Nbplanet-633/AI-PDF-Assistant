# AI PDF Assistant

An AI-powered PDF assistant built with FastAPI, Google Gemini, and PyMuPDF.

## Features

- Upload PDFs
- AI-generated summaries
- Page-wise PDF extraction
- Chunking for Retrieval-Augmented Generation (RAG)
- Semantic search (coming soon)

## Tech Stack

- FastAPI
- Python
- Google Gemini
- PyMuPDF
- Sentence Transformers (planned)
- Qdrant (planned)

## Run

```bash
pip install -r requirements.txt

uvicorn app.main:app --reload
```
